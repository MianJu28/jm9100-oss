## 2. 主 3D 管线的寄存器块

按驱动中的实际执行顺序：`FE`（前端装配）→ `VS`/`TCS`/`TES`/`GS`/`PS`（各着色阶段)→ `RA`（光栅化）→ `SE`（裁剪/建立）→ `VIEWPORT` → `PE`/`MRT`（像素引擎与渲染目标）→ `DEPTH`/`STENCIL`/`HZ`（深度模板）→ `TX`/`SAMPLER`/`TEXTURE`（纹理）→ `MC`/`RS`（显存写入）。

驱动侧对照：`PIPE_SHADER_*` 阶段 → `include/mwv207_state.h` 的 `mwv207_shader_state`；
发射函数见 `mwv207_draw.c` 的 `mwv207_config_*` 系列（详见 `03-DRAW-PIPELINE.md` §3）。

## 4. 驱动号 ↔ 厂商地址

`驱动寄存器号 = 厂商 _Address >> 2`（`07-WINSYS-KMD` 与 `REGISTERS.md` 有完整证据链）。
因此上表的地址范围除以 4 即为驱动侧使用的号段，例如 `DE 0x01308-0x1D000` → 驱动号 `0x04C2-0x7400`。

## 5. 未能推断的块

以下块没有足够的语义线索（无驱动使用位置、名字过于笼统或疑似混淆名），**未做功能推断**：

`TTD`、`WINDOW`
